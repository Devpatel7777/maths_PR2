# Expectation Decider using Probability and Statistics

## Overview

This project analyzes student performance data using Probability and Statistics concepts.
The main objective is to predict the probability of students passing a competitive exam based on different academic factors.

The project includes:

* Dataset generation
* Basic probability calculations
* Empirical and theoretical probability
* Random variable and probability distribution
* Venn diagram conditions
* Contingency table analysis
* Joint, marginal, and conditional probability
* Relationship between events
* Bayes theorem
* Data visualization

---

# Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

---

# Dataset Features

The dataset contains 200 student records with the following columns:

| Column Name         | Description                       |
| ------------------- | --------------------------------- |
| study_hours         | Number of study hours             |
| attendance          | Attendance percentage             |
| group_discussion    | Participation in group discussion |
| previous_test_score | Previous test marks               |
| final_exam_pass     | Final exam result                 |
